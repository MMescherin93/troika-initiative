# Стек инициативы Тройка!

**Initiative tracker for the Russian-language edition of *Troika!***
(official rules: <https://troika.wishport.online>). **The interface is in Russian.**

![Скриншот трекера](https://mmescherin93.github.io/troika-initiative/docs/store-hero.png)

## Что это

В «Тройке!» инициатива — это не бросок, а **Стек с жетонами** (раздел 5 правил):
каждый участник даёт в Стек столько жетонов, какова его Инициатива; Ведущий
вынимает жетон наугад — тот и ходит; выпавший жетон Конца раунда закрывает раунд.
Это расширение ведёт Стек за вас.

Реализовано по правилам:

- **5.1.1** — у персонажа 2 жетона своего цвета; значение Инициативы можно
  изменить для конкретного персонажа (по умолчанию 2)
- **5.1.2** — враги дают столько жетонов, каково их значение Инициативы
- **5.1.3** — жетон Конца раунда, единственный чёрный
- **5.2** — вытягивание жетона наугад: кто выпал, тот и ходит
- **5.3** — Конец раунда: жетоны возвращаются в Стек, раунд +1, убираются
  погибшие
- **5.4** — приспешники дают по одному жетону (значение Инициативы тоже можно
  задать, по умолчанию 1)
- **5.5** — вытянув жетон врага, Ведущий выбирает любого из них
- **6.2.2** — прицелившийся держит свой жетон: со второго жетона кубики
  бросаются дважды
- **6.4** — отсрочка: вытянутый жетон можно вернуть обратно в Стек

## Как пользоваться

1. Нажмите **«Новый раунд»** — Стек соберёт жетоны всех участников и жетон
   Конца раунда.
2. Нажимайте **«Вытянуть жетон»** — расширение выберет, кто ходит.
3. **«Ход завершён»** — жетон ходящего потрачен; **«Прицелиться»** — включает
   двойной бросок по 6.2.2; **«Вернуть в Стек»** — отсрочка по 6.4.
4. Выпал Конец раунда — нажмите **«Новый раунд»**.

Участники добавляются в блоке «Добавить»: имя, тип (персонаж / приспешник /
враг) и значение Инициативы. Правки отменяются кнопкой **«Отменить последнее»**,
состояние можно выгрузить и загрузить файлом («Данные»).

## Кто чем управляет

Расширением управляет **только Ведущий** (роль GM). Игроки видят Стек,
подсказки и журнал, но кнопки у них заблокированы — это сделано специально,
чтобы нельзя было испортить чужой бросок.

Состояние хранится в **метаданных сцены**, поэтому все участники комнаты видят
один и тот же Стек, раунд и журнал. Вне Owlbear Rodeo расширение работает
автономно и хранит состояние в браузере — удобно, чтобы просто попробовать.

## Установка в Owlbear Rodeo

Settings → Extensions → **Add Extension** → вставить ссылку на манифест:

```
https://mmescherin93.github.io/troika-initiative/manifest.json
```

Затем **Install**. Обновляется так же: снять расширение и поставить заново по
той же ссылке.
